# تطبيق Daftar الخاص بك

يلزم وجود Docker و Docker Compose على الجهاز.

## التشغيل

<div dir="ltr">

```sh
./start
```

</div>

{{ACCESS}}

عند التشغيل الأول، أنشئ حساب المالك: بياناتك المستوردة محمَّلة مسبقا.

**لا تستعمل أبدا الأمر <span dir="ltr">`docker compose down -v`</span>: فهو يمسح كل البيانات.**

## النسخ الاحتياطي

<div dir="ltr">

```sh
./backup
```

</div>

تُنشأ أيضا نسخة كل يوم في مجلد <span dir="ltr">`backups/`</span>، وتُحفظ آخر 14 نسخة.

**النسخة الباقية على الجهاز نفسه لا تحمي من العطل.** {{OFFSITE}} حدّد الوجهة في <span dir="ltr">`DAFTAR_OFFSITE`</span> داخل ملف <span dir="ltr">`.env`</span>، ثم شغّل كل يوم:

<div dir="ltr">

```sh
./offsite
```

</div>

تحتوي هذه النسخ على كل بياناتك: احفظها في مكان محمي.

## الاسترجاع

<div dir="ltr">

```sh
./restore backups/FILE.dump
```

</div>

**هذا يستبدل كل البيانات الحالية ببيانات النسخة الاحتياطية.** جرّب ذلك عند تسلّم التطبيق، للتأكد من أن نسخك تعمل.

## احفظ هذا المجلد في مكان آمن

يحتوي ملف <span dir="ltr">`.env`</span> على كلمات سر التطبيق: لا تشاركه. إذا ضاع الجهاز، يكفي تثبيت جديد ونسخة احتياطية لاسترجاع كل شيء، بالحسابات نفسها. سيلزم فقط تسجيل الدخول من جديد.
