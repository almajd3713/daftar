# Fonts

IBM Plex Sans Arabic, in Regular, Medium and Bold, Arabic and Latin subsets, as published by Fontsource (`@fontsource/ibm-plex-sans-arabic` 5.3.0).

Copyright 2019 IBM Corp. Licensed under the SIL Open Font License 1.1: see `OFL.txt`. The files are unmodified.

They're kept here rather than loaded from a CDN because a firm's box has to work with no internet.

Measured when choosing it, against ten other families: it has the Algerian letter ڨ, ڤ, پ, چ and ژ, and all of œ, é and the rest for French, and its Latin digits are tabular.
